# ============================================================
# GEN Z ? the order the database is built in
#
# This file IS the answer to "what order do I run these in". 76 .sql files
# were hand-run over months with nothing recording the sequence, so a fresh
# install was guesswork. Read top to bottom.
#
# Rules
#   ? one filename per line, relative to supabase/
#   ? `#` starts a comment
#   ? `!skip <file>` = deliberately not applied (reason stated above it)
#   ? every .sql in this folder must appear exactly once, either listed or
#     skipped. scripts/sql-verify/fresh_install.py fails if one is neither,
#     so a new migration cannot be forgotten.
#
# The order below was not designed. It was measured: run the replay, read what
# broke, move the file that provides the missing object, repeat. Comments mark
# the dependencies that forced a position, because they are not obvious.
#
# Verified by replay, not by inspection:
#     npm run verify:fresh
# ============================================================
